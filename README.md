# Báo cáo Project: 8 Rooks / Thuật toán AI

## Mục tiêu
- Giải bài toán 8 Rooks trên ma trận 2D bằng các thuật toán AI:
  Hill Climbing, Genetic Algorithm, Local Beam Search, Simulated_Annealing

## Cấu trúc project
├─Algorithm.py (code chưa chỉnh sửa vì giao diện được em chỉnh lại nên chưa thêm thuật toán vào chạy)
├─BFS.py (Thuật toán đã được chỉnh sửa để chạy trên giao diện)
├─Create_target.py
├─Genetic_Algorithm.py
├─GUI.py
├─Hill_Climbing.py
├─Local_Beam_Search.py
├─Main.py
├─Simulated_Annealing.py

## Hướng dẫn chạy
chạy chương trình: main.py
Chọn thuật toán trên giao diện.
